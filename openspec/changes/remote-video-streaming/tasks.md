## 1. 契约与共同起点

- [ ] 1.1 由 02 冻结 `video-stream-analysis.v1` 的五个端点、有界 DTO、OpenAPI 与样例，明确浏览器只提交 `streamSourceId`，并以契约测试验证原始 RTSP、GPU URL 和凭据字段均被拒绝。
- [ ] 1.2 由 00 核对文件归属、供应商真实能力假设和伴随变更依赖，记录新的共同起点 SHA；在 source 映射、TLS/CA、鉴权和停止能力未确认前，所有实时来源保持 disabled。

## 2. Provider 与安全边界（03）

- [ ] 2.1 实现来源查询、会话启动、状态查询、事件查询和停止所需的严格 provider 类型与转换；通过单元测试覆盖未知字段、缺失字段和非法状态。
- [ ] 2.2 实现批准地址、TLS/CA、鉴权和日志脱敏边界；以自动化检查证明响应和日志不包含 RTSP 地址、GPU URL 或凭据。
- [ ] 2.3 覆盖协议故障语义：启动 POST 响应丢失进入 UNKNOWN 且不透明重试，事件查询允许有效空页，供应商未知状态不能被标为成功。

## 3. 持久化与生命周期（04a）

- [ ] 3.1 通过 V002 增量迁移新增 `ai_stream_source`、`ai_stream_session`、`ai_stream_event` 及必要约束；在含既有图片历史的数据库上连续执行两次迁移并记录表、行摘要。
- [ ] 3.2 实现来源授权、会话幂等和派发前持久化；测试匿名、无权限、跨用户来源/会话访问及重复启动冲突。
- [ ] 3.3 实现事件游标、去重、排序和授权截图回存；测试重复事件、乱序事件、有效空事件页及截图归属。
- [ ] 3.4 实现重启恢复、停止确认和终态保护；验证不可查询的已派发会话保持 UNKNOWN，迟到事件不能把 STOPPED、FAILED 或 UNKNOWN 覆盖为运行成功。

## 4. 前端实时事件体验（04b）

- [ ] 4.1 增加已授权来源选择、会话状态、事件时间线与截图页面；用组件及浏览器测试验证空结果、错误、运行中和终态显示。
- [ ] 4.2 为轮询实现离开清理、代次隔离、游标推进和终态保护；验证关闭页面不会自动停止远程会话，旧请求不能覆盖新会话。
- [ ] 4.3 验证无权限、disabled 来源和直接访问均被阻止，且浏览器请求、页面状态和日志不暴露 RTSP 地址、GPU URL 或凭据。

## 5. 真实联调（05）

- [ ] 5.1 从实际 RTX 5070 服务确认来源登记映射、方法、TLS/CA、鉴权、事件查询、停止能力和限额；资料或能力不完整时保留任务未完成并保持实时能力 disabled。
- [ ] 5.2 从实际后端容器完成真实 RTSP 会话启动、事件查询、截图回存、页面展示和历史读取，以 session ID、事件 ID、截图哈希和接口版本串联证据。

## 6. 恢复、故障与观测（06）

- [ ] 6.1 验证重复启动、启动响应丢失和服务重启对账；有供应商查询能力时按远端身份恢复，无查询能力时保持 UNKNOWN 且不重复派发。
- [ ] 6.2 验证事件去重、游标恢复、截图下载断流和迟到事件保护，确保 GPU 离线后既有事件与截图仍可授权访问。
- [ ] 6.3 验证停止竞争、供应商不支持停止、停止响应丢失和确认停止；只有收到供应商确认后才进入 STOPPED。
- [ ] 6.4 增加会话、事件、停止、UNKNOWN 和失败的 Micrometer 指标及滚动日志，验证指标可观测且日志无凭据或 RTSP 秘密。
