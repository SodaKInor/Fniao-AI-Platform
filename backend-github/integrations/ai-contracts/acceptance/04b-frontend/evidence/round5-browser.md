# 第五轮 04b 浏览器验收

时间：2026-09-04。页面：`http://127.0.0.1:18105`。服务仅绑定 loopback，全部能力及成果明确标记为模拟，不代表真实 GPU 联调。

| 场景 | 结果 |
|---|---|
| 导航与来源 | 图片、上传视频、实时事件、历史四个可见入口；任务/会话详情为隐藏路由。可用和 disabled 来源同时显示，停用原因可见。 |
| 视频流程 | MP4 通过 multipart 上传到同一模拟业务 API，`POST /video-jobs` 返回 202；实际任务详情显示“上传视频分析”、带偏移时间线、截图入口和模拟标识，历史页保留并区分任务类型。 |
| 实时运行 | 会话 `demo_stream_0001` 显示 RUNNING、一条去重事件和 `00:00:02.500` 偏移；授权截图从私有资产 API 加载成功。 |
| 正常停止 | 用户明确点击停止后显示 STOPPED；按钮消失。 |
| 停止未知 | 会话 `demo_stream_0002` 的停止响应丢失场景保持 STOP_REQUESTED，页面显示“停止结果待确认”，没有误标 STOPPED 或启动新会话。 |
| 空页与失败 | 空事件会话显示“尚无事件”；失败会话显示 FAILED 和“处理服务暂不可用”，均未伪造成功。 |
| 权限 | 强制只读权限后侧栏仅保留首页，无 AI 工作台；直接访问 `/ai/streams` 转到 `/404` 并显示“不存在或无权访问”。 |
| 请求最小化 | 模拟请求记录只保存 method/path/query/status，不保存令牌、幂等 key 或正文。启动体自动测试证明只有 capabilityCode、streamSourceId、parameters。 |
| 生命周期 | 自动页面和轮询测试证明离开仅停止本地轮询，不调用远程停止；A→B 的迟到成功/失败均被代次隔离。 |

当前浏览器控制层不能直接向文件控件注入本地文件，因此视频文件选择的类型/大小拦截由组件测试覆盖；浏览器成果页面使用同一模拟业务 API 的 multipart 上传记录完成。真实接口、真实媒体处理与正式权限由 05、06、00 后续门禁验证。
